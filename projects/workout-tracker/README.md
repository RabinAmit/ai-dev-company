# Workout Tracker

This is a minimal beginner-friendly web app for logging workouts in the browser.

## Files

- `index.html` contains the page structure and form
- `styles.css` contains the simple layout and visual styling
- `app.js` handles adding workouts, rendering the list, validation, and browser storage

## Features

- Add a workout with date, type, duration, and notes
- View saved workouts in a list
- Keep workouts stored in `localStorage`

## Notes

- No frameworks, libraries, or build tools are used
- The app is intentionally simple for learning and MVP use
