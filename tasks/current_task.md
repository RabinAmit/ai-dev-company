# Current Task

Status: In Progress
Stage: PM

## Task Definition

### Goal
Build a minimal web app that allows users to track workouts.

### Scope
Included:
- Add a workout entry (date, type, duration or notes)
- View a list of past workouts

Excluded:
- User authentication
- Editing or deleting workouts
- Advanced UI/UX
- Analytics or charts
- External integrations

### Constraints
- Keep implementation simple
- No external services or APIs (unless approved)
- Focus on learning and system validation over performance

### Success Criteria
- User can add a workout
- User can see a list of workouts
- Data persists during usage (basic persistence acceptable)
